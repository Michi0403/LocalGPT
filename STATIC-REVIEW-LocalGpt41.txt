LocalGPT 2.1.19 static review
================================

Scope
-----
Source candidate: LocalGpt(41)
Baseline: LocalGpt(40) / LocalGPT 2.1.18
Observed Windows build result: LocalGPT.dll and LocalGPT.xml were produced, then the AfterTargets=Build documentation invocation failed because PowerShell bound only RepositoryRoot and reported AssemblyPath, XmlDocumentationPath, and Version as missing.
Review environment: Linux container without dotnet, PowerShell, Windows WebView, DevExpress build tools, or DocFX execution.

Implemented correction
----------------------
1. Directory.Build.targets no longer quotes a repository-root value ending in a backslash.
   LocalGptDocumentationRepositoryRoot appends a terminal dot, producing an equivalent Windows path ending in "\\.".
   This prevents the native command-line parser from treating the root's final backslash as part of the closing quote boundary.
2. Build-Documentation.ps1 normalizes RepositoryRoot, AssemblyPath, XmlDocumentationPath, and OutputWebRoot immediately with IO.Path.GetFullPath.
3. The script prints a bounded input summary before validating files and invoking DocFX.
4. Existing DocFX HTML/API generation, optional Debug PDF behavior, required Release PDF behavior, Help status API, XML-comment catalog, and translation adapter remain intact.
