# LocalGPT 2.7.6 changelog

## Comprehensive XML documentation restoration and enrichment

- Re-reviewed the maintained C# source documentation from the buildable 2.7.5 baseline and enriched documentation across services, controllers, business objects, persistence models, Council runtime classes, code-generation components, installer code, migrations, helpers, and infrastructure.
- XML documentation now covers **7,494 direct maintained C# type/member declarations**, regardless of public/private/internal accessibility: 651 classes, 139 interfaces, 106 records, 1 struct, 37 enums, 33 constructors, 2,783 methods, 3,269 properties, 458 fields, and 17 events.
- Replaced prior name-only/generated summaries such as `Runs the ... operation`, `Gets or sets ...`, and `Represents a ...` with contextual descriptions derived from the containing domain type, member role, return type, parameters, persistence/API/service responsibility, and current source shape.
- Rich authored XML documentation is preserved rather than normalized back to generated prose.
- Added missing `<param>`, `<typeparam>`, `<returns>`, and property `<value>` documentation where the maintained declaration exposes those contract elements.
- Primary-constructor classes/records receive parameter documentation on their type declaration; private implementation members are documented alongside public API members.
- Generated Designer/g.cs and `<auto-generated>` sources remain excluded from source-authored documentation enforcement.
- Removed one orphaned generator-produced XML block that had been placed inside a `GitHubSourceCacheManifest(...)` call expression in an earlier source package; the actual `GitHubSourceCacheManifest` record now carries the maintained declaration documentation.

## Documentation tooling and build-guard maintenance

- Reworked `build/Add-XmlDocumentation.py` and `build/Assert-XmlDocumentationCoverage.py` around the shared deterministic `build/xml_documentation.py` parser.
- The parser masks C# comments, normal/verbatim/raw strings and only edits documentation attached to direct type/member declarations; it does not inject documentation into method-call arguments, `where` constraints, raw-string templates, or method bodies.
- The assertion now checks contextual non-empty summaries plus required parameter/type-parameter/return/value tags across private as well as public members.
- Re-running the documentation enhancer is idempotent: the completed 2.7.6 tree reports zero additional blocks and zero additional enrichments.
- Corrected the architecture audit's beginning-of-line whitespace expression from newline-spanning `\s*` to horizontal `[ \t]*`. This keeps the static-policy guard strict while preventing masked XML-documentation lines from being swallowed into the following static declaration.

## Source integrity

- A token-equivalence audit confirms that all 407 maintained C# files are code-equivalent to the 2.7.5 baseline after comments are removed; this release changes C# documentation, not application behavior.
- Existing Council/X-Round/live-result, heartbeat, hardware-road, code-generation, workspace, 1-Wire, and build-guard behavior remains intact.
- The generated DocFX `wwwroot/help-docs` snapshot was deliberately **not regenerated** in this source-only environment. The authoritative source comments are now richer; the owner build/DocFX pipeline can regenerate the shipped documentation from them.

## Version

- LocalGPT application/wrapper/installer: **2.7.6**.
- `LocalGPT.WireProtocolVersion` remains **2.1.1**; no wire message contract changed.
