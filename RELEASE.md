# LocalGPT 4.3.2

LocalGPT 4.3.2 restores the documentation contract after the 4.3.1 PDF, Mermaid, glass, and background regressions. Normal builds require the versioned PDF again, hidden-viewer Mermaid diagrams recover, the non-tiled generated sky is visibly primary, and the desktop right rail has real edge spacing.

No .NET build, restore, publish, signing/notarization, GitHub access, or GitHub API operation was performed. See `CHANGELOG-v4.3.2-DOCUMENTATION-PDF-MERMAID-GLASS-RECOVERY.md` and `VALIDATION-v4.3.2-source.md`.
