# LocalGPT 3.4.7

LocalGPT 3.4.7 is the **PowerShell Documentation Progress Parser Repair** release.

It preserves the 3.4.6 cross-platform build/documentation behavior and fixes the documentation progress formatter so Windows PowerShell 5.1 parses the DocFX percentage line correctly. The full release documentation/PDF pipeline, cross-platform guards, existing Node/browser reuse, application behavior, InteractiveServer boundaries, persistence, and wire protocol 2.1.1 remain unchanged.

This handoff is source-only. No .NET build and no GitHub access were used while preparing it. See `CHANGELOG-v3.4.7-POWERSHELL-DOCFX-PROGRESS-PARSER-REPAIR.md` and `VALIDATION-v3.4.7-source.md`.
