# LocalGPT 4.1.6

LocalGPT 4.1.6 is a narrow PowerShell parser repair for the documentation browser retry diagnostics introduced in 4.1.5. It preserves the adaptive low-memory and bounded chunk-recovery behavior unchanged while using parser-safe variable delimiting.

The release also adds a source audit that rejects invalid non-scope `$name:` PowerShell references across maintained `.ps1` files before packaging.

See `CHANGELOG-v4.1.6-POWERSHELL-INTERPOLATION-PARSER-REPAIR.md` and `VALIDATION-v4.1.6-source.md`.
