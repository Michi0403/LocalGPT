# LocalGPT 6.3.0 — Public-test MFA, Stop and Learning Round repair candidate

## Customer-visible defects addressed

1. **1-Wire Authenticator enrollment test:** Pairing-material creation now opens a small DevExpress `DxPopup` containing the enrollment QR, six-digit test field, success/error feedback and close action. A separate `IOneWireRuntimeSecurityService.VerifyCurrentMfaCodeAsync` reads the existing local TOTP seed without creating a new identity, recording the code, establishing peer trust, or altering trust policy. The ordinary pairing UI also has a re-openable **Test authenticator code** action.
2. **Council Stop:** The stop handler now considers the selected active run as well as attached/rejoined run identifiers. The Microsoft.Extensions.AI/DevExpress Chat streaming cancellation token now requests cancellation of the corresponding server-owned Council run rather than merely dropping the visible stream. The Council session's completed-state message retains **stopped by user** when cancellation was requested; new model/HTTP requests still receive the existing cancellation tokens. Native streaming cancellation can also occur on view disposal, so canceled navigations no longer guarantee a resumable background Council run.
3. **Learning Round multi-ZIP semantic gate:** The curator's EOF/hash evidence is still distinct from model-visible source inspection. Bounded recovery now reads successive decoded source pages of selected files from each archive root and includes the actual content in a completed model turn. Only after that turn succeeds are content-free service-origin read-cursor receipts appended to the run; the gate counts no binary/zero-character/incomplete file as a completed semantic read. Model prose, arbitrary JSON and archive hashes cannot create these receipts. The existing database-owned configured workflow proceeds to project synchronization, Knowledge/regex and per-file checklists only after the first gate succeeds.

## Limitations and review requirements

This release is a **source-level repair candidate**, not proof that all ZIP files and regex patterns are now learned. Full repository learning remains a durable, paged checklist. Recovery is deliberately bounded (72,000 characters, eight candidate files per workspace, at most three pages per candidate). Larger files may remain incomplete and later workflow steps must continue them with `localgpt.learning.file.read` and `localgpt.learning.file.review`. No files have been marked completed and no approval gates have been bypassed. The native Stop behavior now prioritizes stopping work over preserving runs on streaming cancellation; navigation/reconnect semantics require regression testing.

No PublisherStudio source changes. Existing PowerShell architecture validation scripts and database migrations are unchanged; no live production user data is bundled.
