# LocalGPT 7.2.8 — common roles and on-disk review proposals

- Data Management → Councils: new "Common roles" section (grid + edit form) stored as runtime value CouncilCommonRolesJson, initially filled from the team templates. "Apply to team roles with the same name" copies the shared fields to every team role with that name after an explicit confirmation. A "Keyaccount reviewer model" picker sets GoalKeyaccountReviewerModelKey (blank = model used by the run).
- codegen.review.create now writes the proposal to disk immediately: CouncilArtifacts/<output name>/<UTC time>-review-<id>-proposed with CHANGE_REVIEW.md, every proposed file and REVIEW_STATUS.md. Nothing is built or run; the approved build still lands in LocalGPT-CodeGeneration/review-<id> and the ZIP.
- DxCheckBox labels: the DevExpress checkbox has no Text parameter, so every label passed as Text was silently dropped (e.g. Data Management preferred models showed bare boxes). All 44 checkboxes now render their label as child content.
- Hyperlight sandbox: added the in-guest runtimes that need no host toolchain: Node.js 22, QuickJS, PHP 8.5, Java 25 (JShell) and BusyBox shell, next to Python, C# and PowerShell. Provision-HyperlightGuestRuntimes.ps1 pulls and hash-pins their images. C, Go, Rust and WASM templates were left out because hluk builds them on the host with a native toolchain (deployment cost).
