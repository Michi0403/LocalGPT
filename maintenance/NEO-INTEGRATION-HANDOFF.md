# LocalGPT and PublisherStudio on MacBook Neo

Neo test on 2026-11-16 with 8 GiB unified memory. Browser tests used installed LocalGPT 7.2.2 and PublisherStudio 4.8.4. Release tests ran on compilestick against LocalGPT 7.2.8 (768667e7) and PublisherStudio 4.8.8 (951610dc). The LocalGPT checkout was then fast-forwarded to 7.3.2 (c985af70). Reproduce application issues on current versions before patching.

## Browser evidence

- Approved the PublisherStudio link in LocalGPT and verified the 1-Wire connection. PublisherStudio → Insert → Media → Create picture with AI sent an apple prompt to LocalGPT Council session a1201249-868d-495c-a51f-fae851b52b9b.
- Ollama rejected requests around 44,000 tokens against a 32,768-token context using phi4-mini-reasoning. The Council closed without a substantive answer, model install approval, or image. Keep a Neo retry at or below 2B. Fit the whole serialized request including tool definitions and reserve output. Limit the request to the relevant media tools and surface context overflow instead of retrying the same oversized payload.
- PublisherStudio's media request checks the installed-model inventory but lacks an explicit missing-model path. Use the existing goal and approvals flow to queue a scoped compatible model install in /chat, then resume the same goal after approval. Verify runtime readiness, the generated media receipt, and insertion back into PublisherStudio. Hugging Face metadata search returned stabilityai/sd-turbo. Python execution, model installation, generation, and insertion still need verification.
- In LocalGPT Chat, qwen2.5-coder:1.5b returned C# for summing integer arguments. The exact reply failed .NET 10 compilation with CS0127 because void Main returned integer values. It also rejected multiple arguments. Use the compiler and valid/invalid invocation results as acceptance criteria for the UI coding workflow. The repair prompt was submitted, but its result was unverified.
- In /install → Setup guide → Ollama storage & server, Save & restart loaded models from LegendStick. Selecting the SSD folder through Browse and restarting restored the eight-model SSD inventory. The saved and live stores were left on the SSD. Typed path changes appeared in the field before the persisted path changed. Folder selection plus restart was verified.

## Releases

- LocalGPT 7.2.8 completed the official osx-arm64 release. Apple accepted both the signed DMG and PKG. The validated embedded PDF had 4,982 pages and used 242 parts at eight source HTML pages per batch. The Neo runs kept that batch size. Ghostscript provisioning could not find Homebrew. The already-committed 7.3.2 Pages ZIP was independently checked and contains 7.3.2 documentation metadata. Keep Pages snapshots matched to the release that produced them.
- LocalGPT PDF hang reproduced even after Edge wrote a complete cover. A detached Edge helper held a redirected stderr pipe open. A temporary bounded diagnostic drain, followed by normal PDF validation, let the full render complete. Recommend replacing unconditional task Result reads in build/Build-Documentation.ps1 with bounded waits after process cleanup.
- PublisherStudio blocked on application 4.8.8 versus installer 4.8.7. Temporarily aligning the installer let it render and merge all 100 documentation parts. It then failed because PublisherStudio.Web.csproj validates wwwroot/help-docs in AfterTargets=Publish while the RID lane disables doc generation and copies prepared help only after dotnet publish returns. Supply prepared docs before the MSBuild assertion, or explicitly defer that assertion to the release stage that copies and verifies them. Preserve the final package documentation validation.
- A temporary PublisherStudio change removed the repeated file-stability wait when PDF completion had already been verified before browser shutdown. The PDF completed with final validation. Comparative speed remains unmeasured.
- Temporary source edits were removed from both stick checkouts. Build logs are available on the Neo at /Volumes/compilestick/localgpt/artifacts/neo-localgpt-release-resume.log and /Volumes/compilestick/blazorpublisher/artifacts/neo-publisher-release-resume.log. Neither app was upgraded during the browser test.
