# LocalGPT 2.2.2

This patch follows the already published 2.2.1 release. It keeps every frontend feature and moves the follow-up maintenance work to a new application version instead of republishing 2.2.1.

- Completes culture selection through a full request, persistent application-wide culture cookie, request-culture query values and cache-safe browser localization refresh.
- Retains the native AI-provider and AI Council selector inside the Chat configuration workspace.
- Keeps the ASCII-game guide mounted, reserves balanced layout space and prevents control interactions from moving the full page.
- Searches trusted installed documentation trees for the newest matching HTML, XML and `LocalGPT-2.2.2.pdf` payload.
- Uses resilient DX-function catalog reconciliation for legacy rows and SQLite uniqueness races without deleting user policy choices.
- Keeps GitHub Pages API navigation on the generated `api/index.html` output.
- Preserves the compact Kawaii DocFX presentation, recursive installed-documentation lookup, responsive Test Lab workspaces and architecture/static-policy compliance.
- Leaves the independently versioned `LocalGPT.WireProtocolVersion` package at version 2.1.0.
