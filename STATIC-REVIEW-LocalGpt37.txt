LocalGPT 2.1.15 / LocalGpt(37) static review
================================================

Purpose
-------
This patch release corrects the first Windows/.NET build findings reported for
LocalGPT 2.1.14. It does not remove or redesign the embedded workbench,
workspace environment, controller, DXFunction, organic capability, migration,
or safety-boundary work from 2.1.14.

Reported failures addressed
---------------------------
1. Assert-IteratorExceptionPolicy.ps1 rejected two new yield helpers in
   EmbeddedHardwareCatalogService.cs:
   - GetProfileDirectories()
   - CreateFallbackProfiles()

   Resolution: both helpers now return concrete read-only list results. The
   repository policy was not weakened and no baseline exception was added.

2. EmbeddedFirmwarePlanningService.cs contained malformed interpolated
   multiline raw strings beginning in the Arduino sketch generator and
   cascading through PlatformIO and wiring-Markdown generation.

   Resolution: the three artifact generators now use explicit StringBuilder
   output. This removes the raw-string delimiter/indentation failure and makes
   C++, JSON, INI and Markdown escaping explicit.

3. The Visual Studio NuGet/project-details message occurred before a successful
   LocalGPT project evaluation. This patch changes no package reference or feed
   configuration. The authoritative follow-up is a clean restore/rebuild on the
   Windows development machine after replacing the source tree.

Validation completed in this packaging environment
--------------------------------------------------
- Async continuation audit passed for 133 source files:
  1985 await tokens, 1704 ConfigureAwait(false), 123 renderer-affine
  ConfigureAwait(true), 2 preconfigured awaitables, 154 reviewed await-using
  disposals, and 2 configured async streams.
- Application architecture audit passed.
- Iterator policy logic was emulated against the repository baseline; no new
  unbaselined iterator findings remain.
- 22 JSON files parsed successfully.
- 9 XML/project/configuration files parsed successfully.
- 357 C# source files passed lexical closure and structural-delimiter checks.
- No unresolved Git merge markers were found.
- No bin, obj, .pio, DLL, EXE, PDB, OBJ or firmware BIN output was included.
- A representative generated Arduino/ESP32 sketch, including analog telemetry
  and physical 1-Wire calls, passed g++ -std=c++17 -fsyntax-only with minimal
  Arduino/OneWire stubs.

Limitations
-----------
This environment does not contain the pinned .NET 10 SDK, Windows WebView2
workload, DevExpress dependencies, or the user's package-feed configuration.
Therefore a real restore and Debug/Release build was not claimed. The user's
Windows build remains the semantic compiler and runtime authority.
