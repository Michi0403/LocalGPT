# README image plan

This folder is reserved for the public repository landing-page images.

Recommended files:

| File | Suggested content | Suggested size |
|---|---|---|
| `localgpt-hero.png` | Wide overview combining Chat, Council output, Council Teams, and Theme Fusion | 1600 × 900 |
| `chat-streaming.png` | Streamed thinking/final-answer panels in the main chat | 1400 × 900 |
| `council-teams.png` | Role and workflow editor with AI/human participation controls | 1400 × 900 |
| `human-collaboration.png` | Collaboration inbox, approval, or human contribution workflow | 1400 × 900 |
| `theme-fusion.png` | Wide Theme Fusion panel and a distinctive combined theme | 1400 × 900 |

Guidelines:

- Use current builds rather than old release screenshots.
- Avoid private prompts, API keys, local paths, personal messages, or identifying database content.
- Prefer one clear focal point per screenshot.
- Capture at a readable desktop resolution.
- Compress images before committing while keeping UI text legible.
- Update `README.md` to replace the visible placeholders only after the corresponding image exists.
