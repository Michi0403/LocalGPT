# Chat and AI Council

The Chat page is the primary user surface. Configuration is deliberately collapsible so the transcript keeps the available viewport at normal browser zoom.

## Roles

- The selected chat provider answers ordinary requests.
- A Council team assigns explicit roles, models, runtime classes and workflow steps.
- Human contributions can join a running Council without replacing the authoritative session state.
- Model routes and resource limits remain user-configurable.

## Configuration panels

Chat configuration panels use responsive dialog sizing. On wide displays they use most of the viewport; on smaller displays they become nearly full-screen and keep one internal scroll owner.
