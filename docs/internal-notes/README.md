# Internal documentation source notes

This directory preserves superseded design notes, release-specific articles, experiments, and learning-process material exactly as they existed before the documentation rework.

They are **not** part of the public DocFX site. Their durable architecture, constraints, and implementation lessons were folded into the curated `guide`, `architecture`, `engineering`, and `reference` sections. Keeping the original notes here prevents information loss while avoiding a reader experience dominated by prototypes, local archive paths, build-pass narration, or temporary version patches.

Do not treat these files as current product truth when a maintained page says otherwise.
