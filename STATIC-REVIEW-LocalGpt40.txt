LocalGPT 2.1.18 static review
================================

Scope
-----
Source candidate: LocalGpt(40)
Baseline: LocalGpt(39) / LocalGPT 2.1.17
Review environment: Linux container without dotnet, csc, PowerShell, Windows WebView, DevExpress build tools, or DocFX execution.

Implemented release changes
---------------------------
1. Startup project seeding
   - Existing LocalGPT Core and Humanitarian project graphs are loaded with AsNoTracking and AsSplitQuery.
   - Existing parent and child entities remain detached.
   - Only missing topic/version/revision/requirement/artifact records are added directly.
   - The bounded concurrency fallback remains for genuinely concurrent writers.

2. Authoritative GameDirector
   - Player and AI controls are proposals reviewed before state mutation.
   - A second expected-turn check prevents stale approved proposals from being applied.
   - Creature and reactive-object subdirectors provide bounded predictions.
   - A factory creates actor runtime descriptors and Council assignment slots without state-mutation authority.
   - HTTP and DXFunction preview contracts are included.
   - CouncilModelPreferred records the configured reviewer model; deterministic checks remain final. This release does not yet invoke an LLM for the director review.

3. Documentation
   - Compiler XML documentation is enabled for LocalGPT.
   - A repository-local DocFX 2.78.5 tool manifest and documentation project are included.
   - The Windows build target generates API/HTML documentation and attempts a versioned PDF.
   - Release builds require the PDF by default; the property can be explicitly overridden.
   - The Help page is a launcher/status page for generated documentation.
   - A documentation catalog, translation adapter, version metadata attribute, controller, and bounded XML-comment search API are included.

4. Chat layout
   - Expanded Chat Configuration and Running Session Tools use near-viewport modal workspaces.
   - Visible DevExpress configuration/dialog surfaces are marked by the existing guarded browser adapter and receive responsive viewport dimensions.
   - Narrow-screen overrides are included.
